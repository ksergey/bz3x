КАКОЙ РАЗЪЁМ (bZ3X)

Два OBD-разъёма. Рабочий для ГУ — СПРАВА, со стороны пассажира (не левый под рулём).

3/11  MS-CAN -> ГУ  <= этот
6/14  HS-CAN
4/5   GND
16    +12V

На правильном STP53 + 22F190 проходят; на неправильном — CAN ERROR.

СТОП при ? / ERROR / NO DATA / CAN ERROR / BUS ERROR / UNABLE TO CONNECT / 7F xx xx.
Версия должна быть 8789CVN020  S.242, иначе ключ не отправлять.
Шина IHU — MS-CAN 125k (STP53, пины OBD 3/11).
Если на STP53 вернулось ? — адаптер/прошивка без MS-CAN; запасной вариант — ATTP6 / STP33 (HS-CAN 500k, пины 6/14).
seed→key считается на самой странице (keybar внизу или /key <seed>); строка 2702<KEY> подставит текущий ключ.
