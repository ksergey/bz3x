Что это

Клиент ADB поверх WebUSB — прямо в браузере, без установки adb на компьютер. Поддерживается в Chrome / Edge на desktop и Android (не в iOS/Safari).

Подготовка телефона

  • Включи Параметры разработчика и Отладку по USB.
  • Подключи кабелем, нажми иконку «вилки» сверху, выбери устройство.
  • На телефоне подтверди запрос «Разрешить отладку по USB» (галка «всегда» — чтобы не спрашивал снова).

Терминал

Любая строка уходит как shell-команда (shell:<строка>), результат — в лог. Примеры:

  • getprop ro.product.model — модель
  • pm list packages -3 — сторонние приложения
  • dumpsys battery — состояние батареи
  • wm size — разрешение экрана
  • settings list global — глобальные настройки

Локальные команды

  • /help — эта справка
  • /connect — выбрать и подключить устройство
  • /disconnect — отключить
  • /info — свойства устройства
  • /reboot — перезагрузка · /reboot bootloader · /reboot recovery
  • /key — показать отпечаток локального RSA-ключа
  • /clear — очистить лог

Заметки

Ключ RSA генерируется в браузере и хранится в localStorage — после галки «всегда разрешать» телефон запоминает его и больше не спрашивает. Каждая команда — одноразовый shell:-поток; интерактивный pty-shell не используется.
