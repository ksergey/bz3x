# bZ3X · веб‑терминал + команды (GitHub Pages)

Страницы:

- **`index.html`** — **веб‑терминал (TUI)**: моноширинный лог‑экран, нижний prompt
  со слэш‑командами (`/connect`, `/ble`, `/key …`, `/vin`, `/dtc`,
  `/card`), статус‑строка. Сам открывает адаптер из браузера (Web Serial для
  USB/RFCOMM и Web Bluetooth для BLE), шлёт всю последовательность с проверками,
  лог TX/RX, авто‑подстановка seed→key и отправка `2702<KEY>`. TesterPresent‑keepalive
  держит сессию; при ошибке протокол восстанавливается. **Шпаргалка встроена**
  (`/card` или ссылка в статус‑строке): команды + ожидаемые ответы, клик — вставить
  команду в prompt. Шина — **HS‑CAN** (ATTP6, пины OBD 6/14). Есть **lockout
  auth‑pending**: после незавершённой
  авторизации повтор ключа блокируется (хранится в браузере) до `/authreset`.
  Вверху **вкладки**: «Терминал» (ручной режим); «Процедура» — повтор последовательности
  `bz3x-menu.exe`/`bz3x-russian.exe` в один клик с переключателем шины **MS/HS** и двумя
  действиями — «открыть меню» (`31012B00`) и «включить ADB» (`3101AE6501`), с пошаговым
  статусом (✓/×), валидацией ответов (формат VIN, версия S.242, битрейт HS-CAN 500000,
  подтверждение `71012B00`/`7101AE6500`) и итогом PASS/FAIL; «ADB» — справка (что `bz3x-russian.exe`
  делает по ADB, без действий); «Шпаргалка» — распиновка и команды.
- **`terminal-classic.html`** — прежний веб‑терминал с кнопками (тот же обмен,
  те же фиксы: keepalive, дренаж RX, восстановление протокола).
- **`card.html`** — отдельная standalone‑шпаргалка (команды + офлайн‑генератор
  ключа Seed→Key, AES‑128). Необязательна — то же есть внутри `index.html` по `/card`.

## Веб‑терминал (`index.html`)

- **Web Serial** — Chrome/Edge на компьютере (USB‑адаптеры) и **Chrome for Android
  117+** (Bluetooth RFCOMM/SPP, т.е. vLinker MC+ по классическому BT). Нужен HTTPS
  или `localhost`; на Android — заранее спарить адаптер.
- **Web Bluetooth** — BLE‑режим адаптера. UUID сервиса у разных моделей свой; если
  авто‑поиск не находит, есть поле для ручного UUID и кнопка «Показать сервисы
  устройства».
- Авто‑baud (38400/115200/9600/57600), сырой RX (`/raw on`), ручная отправка
  любой команды, подтверждение риска перед последовательностью (`/run yes`).
- Во вкладке «Скан» терминал пассивно слушает HS‑CAN (ATMA) на 500k/250k/125k —
  видно сразу, где живой трафик.
