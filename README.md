# bZ3X · веб‑терминал + команды (GitHub Pages)

Инструменты для чтения VIN и работы с UDS на головном устройстве Toyota bZ3X через
OBD‑адаптер (ELM327 / STN / vLinker). Шина ГУ — **HS‑CAN**, 500 кбит/с, 11‑бит,
пины OBD **6/14**. Адрес запроса `0x72B`, ответа `0x7AB`.

## Содержимое

- **`index.html`** — **веб‑терминал (TUI)**: моноширинный лог‑экран, нижний prompt
  со слэш‑командами, статус‑строка. Сам открывает адаптер из браузера (Web Serial для
  USB/RFCOMM и Web Bluetooth для BLE), лог TX/RX, авто‑подстановка seed→key и отправка
  `2702<KEY>`. TesterPresent‑keepalive держит сессию; при ошибке протокол восстанавливается.
  Четыре вкладки:
  - **Терминал** — ручной режим, любая команда (`ATI`, `22F190`, `2701` …) или слэш‑команда.
  - **Команды** — чеклист инициализации (`ATE0…ATSTFF`, `ATTP6` = HS‑CAN 500k) + VIN,
    открытие меню (`31012B00`) и включение ADB (`3101AE6501`); отметить нужное и
    «отправить в терминал» — команды уйдут по порядку с валидацией ответов.
  - **Скан** — пассивный поиск живой шины через `ATMA` (HS‑CAN 500k/250k/125k).
    Только слушает, в шину ничего не передаёт — приборку не трогает.
  - **Шпаргалка** — распиновка OBD и команды с ожидаемыми ответами; клик по команде
    вставляет её в prompt.
- **`bz3x_commands.md`** — текстовая шпаргалка команд для ручной работы в любом
  serial‑терминале (minicom, Serial USB/Bluetooth Terminal): блоки для ELS27/STN и
  обычного ELM327, vLinker MC+, read‑only разведчик по UDS, справочник DID и
  **блок DoIP (UDS по Ethernet, ISO 13400) для Linux** с готовым Python‑скриптом.
- **`diagnostic.py`** — консольный preflight: перебор baud, выбор HS‑CAN, чтение VIN
  (`22F190`), только чтение; отчёт пишется в текущую директорию. Работает под Linux.

## Слэш‑команды терминала

`/help` · `/connect [baud]` (USB/BT‑SPP) · `/ble [uuid]` · `/services` · `/disconnect` ·
`/ati` · `/vin` · `/dtc` · `/key <seed8hex>` (seed→key офлайн) · `/card` (шпаргалка) ·
`/raw on|off` · `/clear`. Любой другой ввод уходит в адаптер как есть.

## Веб‑терминал (`index.html`)

- **Web Serial** — Chrome/Edge на компьютере (USB‑адаптеры) и **Chrome for Android 117+**
  (Bluetooth RFCOMM/SPP, т.е. vLinker по классическому BT). Нужен HTTPS или `localhost`;
  на Android адаптер нужно заранее спарить.
- **Web Bluetooth** — BLE‑режим адаптера. UUID сервиса у разных моделей свой; если
  авто‑поиск не находит, есть поле для ручного UUID и кнопка «Показать сервисы устройства».
- Авто‑baud (38400/115200/9600/57600), сырой RX (`/raw on`), офлайн‑генератор ключа
  seed→key (AES‑128) прямо на странице.

## Оффлайн

`index.html` самодостаточен: скачайте его и откройте в браузере телефона. Генератор ключа,
буфер обмена и кнопки работают и без сети. «Живое» подключение требует Chrome/Edge и
безопасного контекста (HTTPS или `localhost`), поэтому удобнее через GitHub Pages.

> ⚠️ Машина в «P», питание ГУ включено, другие программы диагностики закрыты.
> Настройки CAN самого адаптера после работы могут остаться изменёнными (протокол/скорость) —
> сбрасывается `ATZ` или переподключением адаптера. В автомобиль ничего не пишется при чтении VIN.
